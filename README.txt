SIGNTA WEBSITE SOURCE

QUICK PREVIEW
Extract this ZIP and open index.html in Chrome. No installation is needed.
The file includes the mascot, compiled React component, styles, and animations.

EDIT AND REBUILD
1. Install Node.js with npm.
2. Open a terminal inside the extracted project folder.
3. Run: npm ci
4. Edit src/WhatWeDo.jsx for portfolio content and cards.
5. Edit src/input.css for portfolio styling and src/template.html for the rest of the website.
6. Run: npm run build
7. Open the rebuilt index.html.

The consultation form is a demo: no submissions are sent or stored.
The uploaded mascot is included as supplied.
